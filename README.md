# Social Paradox

Miernik CO2 „kiedy i jak wietrzyć” (hackathon GrowUp): urządzenie mierzy CO2,
temperaturę i wilgotność w małym pokoju, aplikacja mobilna (iOS + Android)
łączy się z nim przez BLE i podpowiada, kiedy i jak długo wietrzyć.

| Katalog     | Co                                                |
|-------------|---------------------------------------------------|
| `firmware/` | M5StickC Plus2 + SCD41 (PlatformIO, Arduino)      |
| `app/`      | aplikacja Flutter                                 |
| `docs/`     | dokumentacja, kontrakt BLE (`ble-protocol.md`)    |
| `tools/`    | skrypty pomocnicze                                |

Zasady pracy w repo: [CONTRIBUTING.md](CONTRIBUTING.md).
